# Regression and Prediction (Linear Models)

This repository demonstrates **simple and multiple linear regression** using Python and `statsmodels`, including:
- **ChickWeight** dataset: R² and significance test (p-value at α = 0.05)
- **women** dataset: simple regression and weight prediction from height
- **Fish.csv** dataset: multiple regression and predicting fish weight for given measurements

---

## Files
- `Regression_Models.py` — Main script (all tasks in one file)
- `Fish.csv` — Dataset used for multiple linear regression
